  <action>
Create `src/loop/sdl3_loop.c` implementing the frame loop helper functions. Follow the established pattern of sdl3_init.c (file-local static state, functions called from sdl3_module.c):

1. **Delta time computation** -- `sdl3_loop_init()` and `sdl3_compute_delta()`:
   - File-local statics: `s_perf_frequency` (Uint64), `s_last_counter` (Uint64), `s_initialized` (bool)
   - `sdl3_loop_init()`: sets `s_perf_frequency = SDL_GetPerformanceFrequency()`, `s_last_counter = SDL_GetPerformanceCounter()`, `s_initialized = true`
   - `sdl3_compute_delta()`: if not initialized, call `sdl3_loop_init()` and return 0.0f (first-frame safety). Otherwise compute `dt = (float)(now - s_last_counter) / (float)s_perf_frequency`, update `s_last_counter = now`, clamp to `[0.0f, 0.25f]` (SDL3_MAX_DELTA), return dt
   - CRITICAL: Cast to float BEFORE dividing to avoid integer division producing 0

2. **FPS tracking** -- `sdl3_compute_fps(float dt)`:
   - File-local static `s_smoothed_fps` (float, init 0.0f)
   - Compute `raw_fps = (dt > 0.0001f) ? (1.0f / dt) : 0.0f`
   - Exponential moving average: `s_smoothed_fps = 0.1f * raw_fps + 0.9f * s_smoothed_fps`
   - Return smoothed FPS value

3. **Frame rate capping** -- `sdl3_cap_frame_rate(Uint64 frame_start_ns, int target_fps)`:
   - If `target_fps <= 0`, return immediately (no cap / VSync mode)
   - Compute `target_ns = SDL_NS_PER_SECOND / (Uint64)target_fps`
   - Compute `elapsed_ns = SDL_GetTicksNS() - frame_start_ns`
   - If `elapsed_ns < target_ns`, call `SDL_DelayNS(target_ns - elapsed_ns)` (OS scheduler, low CPU)

4. **Minimized pause check** -- `sdl3_all_windows_minimized()`:
   - This function needs access to window component IDs. Since it cannot use CEL macros (per-TU constraint), implement it as a simple bool that the event pump system in sdl3_module.c can call.
   - Actually, since this needs ECS queries which require the per-TU macros, this logic should live in sdl3_module.c inline in the event pump system body. Instead, provide a simpler helper: `sdl3_frame_state_init()` that initializes the SDL3_FrameState CEL_State with `running = true`, and `sdl3_frame_state_update(float dt, float fps)` that updates delta_time, fps, smoothed_fps fields.

5. **Public API functions** -- `sdl3_should_run()` and `sdl3_delta()`:
   - `sdl3_should_run()`: reads `cels_running()` -- returns true if CELS quit flag is not set. This is the consumer's while-loop condition.
   - `sdl3_delta()`: calls `sdl3_compute_delta()` -- computes and returns the delta time for this frame. Consumer calls this once per frame and passes result to `cels_step()`.

Update `include/cels_sdl3.h` -- add after the Window Types section:

```c
/* ============================================================================
 * Frame Loop Types
 * ============================================================================ */

/*
 * Frame loop configuration. Set target_fps to 0 for uncapped / VSync-only.
 */
typedef struct SDL3_FrameConfig {
    int target_fps;     /* 0 = uncapped, >0 = cap to this FPS */
} SDL3_FrameConfig;

/*
 * Frame loop state singleton. Tracks running status and timing data.
 * Read via cel_read(SDL3_FrameState) in consumer systems.
 *
 * running:      false when all windows CLOSED or SDL_QUIT received
 * delta_time:   seconds elapsed since last frame
 * fps:          raw frames per second (1/dt)
 * smoothed_fps: exponential moving average FPS for display
 */
CEL_Define_State(SDL3_FrameState) {
    bool  running;
    float delta_time;
    float fps;
    float smoothed_fps;
};

/* Frame loop public API */
extern bool  sdl3_should_run(void);
extern float sdl3_delta(void);
```

  <action>
Add two new CELS systems and update module registration in `sdl3_module.c`:

1. **SDL3_EventPumpSystem** (OnLoad phase, runs BEFORE SDL3_WindowStateSystem):
   - Uses `cel_run { ... }` (no entity query -- this is a global system)
   - First, check if all windows are minimized by iterating SDL3_WindowComponent entities:
     - Do a `cel_query(SDL3_WindowComponent)` + `cel_each` scan. Count total windows, count minimized windows. If total > 0 and total == minimized, set a local `all_minimized` flag.
   - If `all_minimized` is true: call `SDL_WaitEvent(&event)` to block with zero CPU. Process the returned event (check for SDL_EVENT_QUIT, window events). Then return (skip poll loop this frame -- the waking event is enough).
   - Normal path: `while (SDL_PollEvent(&event))` loop draining all events:
     - `SDL_EVENT_QUIT`: call `cel_quit()` and return immediately
     - `SDL_EVENT_WINDOW_CLOSE_REQUESTED`, `SDL_EVENT_WINDOW_MINIMIZED`, `SDL_EVENT_WINDOW_RESTORED`, `SDL_EVENT_WINDOW_RESIZED`: find the matching window entity by iterating SDL3_WindowComponent entities and comparing `window_id` to `event.window.windowID`. Once found, call `sdl3_window_handle_event()` on that component with the event type and data1/data2 from the event. Use `cel_update(SDL3_WindowComponent)` to ensure the mutation is properly tracked by the ECS.
     - All other events: ignore (Phase 4 will add raw event buffer)

   IMPORTANT: The event routing to windows is new -- previously the example had no event pump. The `sdl3_window_handle_event` function already exists in sdl3_window.c and handles all state transitions. We need to find the right entity by matching `event.window.windowID` against each `SDL3_WindowComponent->window_id`.

   NOTE on window event data: For `SDL_EVENT_WINDOW_RESIZED`, `event.window.data1` = new width, `event.window.data2` = new height. For other window events, data1/data2 are not used by sdl3_window_handle_event (it only reads event_type for those).

2. **SDL3_FrameStateSystem** (OnLoad phase, runs AFTER SDL3_WindowStateSystem):
   - Uses `cel_run { ... }` (no entity query)
   - Read SDL3_FrameState via the state singleton
   - Check if all windows are CLOSED: iterate SDL3_WindowComponent entities. Count total, count CLOSED. If total > 0 and total == closed_count, set running to false via `cel_mutate(SDL3_FrameState)`.
   - Also update delta_time, fps, smoothed_fps in SDL3_FrameState each frame (read from sdl3_compute_delta/sdl3_compute_fps results cached during sdl3_delta() call -- but since sdl3_delta() is called by the consumer BEFORE cels_step(), the values need to be available. Store last-computed values in sdl3_loop.c statics and expose via getter functions like `sdl3_get_last_delta()` and `sdl3_get_last_fps()`).
   - Simpler approach: The frame state system just checks window states and manages the running flag. Delta time and FPS are updated by sdl3_delta() which the consumer calls before cels_step(). The SDL3_FrameState is updated in sdl3_loop.c when sdl3_delta() is called.

3. **CEL_State(SDL3_FrameState)** declaration and initialization:
   - Add `CEL_State(SDL3_FrameState);` at the top of sdl3_module.c (same pattern as SDL3_ContextState)
   - BUT: SDL3_FrameState data ownership lives in sdl3_loop.c (same pattern as SDL3_ContextState in sdl3_init.c). So actually the CEL_State declaration stays in sdl3_module.c but the static data and register/bind live in sdl3_loop.c.
   - In sdl3_loop.c: add static `struct SDL3_FrameState SDL3_FrameState = { .running = true, ... }` and in `sdl3_loop_init()` call `SDL3_FrameState_register()` and `cels_state_bind(SDL3_FrameState)`.
   - Then `sdl3_should_run()` reads `SDL3_FrameState.running && cels_running()`.
   - `sdl3_delta()` computes delta, updates `SDL3_FrameState.delta_time`, `.fps`, `.smoothed_fps`.

4. **Module registration update** in `CEL_Module(SDL3_Engine, init)`:
   - Add `SDL3_FrameState` to registration
   - Add `SDL3_EventPumpSystem` and `SDL3_FrameStateSystem` to registration
   - Registration order matters for system execution within the same phase. Register SDL3_EventPumpSystem FIRST, then SDL3_WindowStateSystem, then SDL3_FrameStateSystem. This ensures pump->window-state->frame-state ordering within OnLoad.

CRITICAL ordering of existing registrations: Currently the module registers `SDL3_WindowConfig, SDL3_WindowComponent, SDL3_WindowLC, SDL3_WindowStateSystem`. The new systems must be interleaved:
```c
cels_register(SDL3_ContextState, SDL3_ContextLC, SDL3_ContextConfig);
cels_register(SDL3_FrameState, SDL3_EventPumpSystem);
cels_register(SDL3_WindowConfig, SDL3_WindowComponent,
              SDL3_WindowLC, SDL3_WindowStateSystem);
cels_register(SDL3_FrameStateSystem);
```

This ensures: EventPump (drains events, routes to windows) -> WindowState (CLOSING->CLOSED transitions) -> FrameState (checks if all windows closed).
