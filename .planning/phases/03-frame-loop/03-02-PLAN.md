  <action>
Create `examples/frame-loop/main.c` demonstrating the canonical consumer loop pattern from CONTEXT.md. Follow the structure of `examples/minimal/main.c` but replace the hardcoded delta and frame counter with the real frame loop API.

The example should:

1. **World composition**: One window (`SDL3Window(.title = "Frame Loop Demo", .width = 800, .height = 600)`) with SDL3Context.

2. **FPS reporter system** (OnUpdate phase): A system that runs each frame and prints FPS info periodically (every ~1 second based on accumulated delta time). Use `cel_delta()` inside the system to get delta time. Accumulate time in a static float, and when >= 1.0 second, print:
   ```
   FPS: %.1f (dt: %.4fs)
   ```
   reading from `cel_read(SDL3_FrameState)` for smoothed_fps and delta_time. Reset accumulator after printing.

3. **Frame counter system** (OnUpdate phase): Counts frames. After 300 frames (~5 seconds at 60fps), calls `cel_quit()` to exit. This gives enough frames to see FPS stabilize. Print frame count at exit:
   ```
   Frame loop complete: %d frames
   ```

4. **Main function**: The canonical consumer pattern:
   ```c
   cels_main() {
       cels_register(SDL3_Engine);
       cels_register(FPSReporter, FrameCounter);
       cels_session(World) {
           while (sdl3_should_run()) {
               float dt = sdl3_delta();
               cels_step(dt);
           }
       }
       printf("Session complete -- clean exit\n");
   }
   ```

5. **No SDL_Delay** in this example -- let the loop run uncapped to demonstrate real delta time measurement. The FPS should show a high value (hundreds or thousands on modern hardware) since there is no rendering or frame capping yet.

Update `CMakeLists.txt` -- in the examples section, add:
```cmake
add_executable(frame-loop examples/frame-loop/main.c)
target_link_libraries(frame-loop PRIVATE cels-sdl3)
set_target_properties(frame-loop PROPERTIES C_STANDARD 99 C_STANDARD_REQUIRED ON)
```
