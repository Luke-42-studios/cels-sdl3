CEL_Compose(TextEntities) {

**Text interaction system (OnUpdate):**
Create `CEL_System(TextInteraction, .phase = OnUpdate)` that:
1. Reads SDL3_EventQueue from the window entity (query SDL3_EventQueue)
2. On key press:
   - `1`: Change dynamic text color to red {255, 0, 0, 255}
   - `2`: Change dynamic text color to green {0, 255, 0, 255}
   - `3`: Change dynamic text color to blue {100, 149, 237, 255}
   - `SPACE`: Toggle text content between "Hello, World!" and "Text changed!"
   - `ESCAPE`: cel_quit()
3. Apply changes via cel_update(SDL3_Text) on the dynamic text entity

For identifying the "dynamic" text entity: Query SDL3_Text entities and match by position or by tracking the entity ID from spawning. The simplest approach: iterate all SDL3_Text entities and only modify the one at y=250 (or use a marker component). Even simpler: just modify ALL text entities' colors on 1/2/3 keys.

Actually, the most practical pattern: have the TextInteraction system query both SDL3_EventQueue (to read input) and SDL3_Text (to modify text). Since these are on different entities, you'll need two separate cel_each blocks. First block reads events into local variables, second block applies changes.

```c
CEL_System(TextInteraction, .phase = OnUpdate) {
    /* Collect input from window events */
    static const char* texts[] = {"Hello, World!", "Text changed!"};
    static int text_idx = 0;
    SDL_Color new_color = {0};
    bool color_change = false;
    bool text_change = false;
    bool quit = false;

    cel_query(SDL3_EventQueue);
    cel_each(SDL3_EventQueue) {
        for (int i = 0; i < SDL3_EventQueue->count; i++) {
            const SDL_Event* ev = &SDL3_EventQueue->events[i];
            if (ev->type != SDL_EVENT_KEY_DOWN || ev->key.repeat) continue;
            switch (ev->key.key) {
                case SDLK_1: new_color = (SDL_Color){255, 80, 80, 255}; color_change = true; break;
                case SDLK_2: new_color = (SDL_Color){80, 255, 80, 255}; color_change = true; break;
                case SDLK_3: new_color = (SDL_Color){100, 149, 237, 255}; color_change = true; break;
                case SDLK_SPACE: text_idx = 1 - text_idx; text_change = true; break;
                case SDLK_ESCAPE: quit = true; break;
            }
        }
    }

    if (quit) { cel_quit(); return; }

    /* Apply changes to dynamic text entity (the one at y=250) */
    if (color_change || text_change) {
        cel_query(SDL3_Text);
        cel_each(SDL3_Text) {
            if (SDL3_Text->y > 200.0f && SDL3_Text->y < 300.0f) {
                cel_update(SDL3_Text) {
                    if (color_change) SDL3_Text->color = new_color;
                    if (text_change) SDL3_Text->string = texts[text_idx];
                }
            }
        }
    }
}
```

**Main function:**
```c
cels_main() {
    cels_register(SDL3_Engine);
    cels_register(FontLoader);
    cels_register(TextSpawner);  /* or however entities are created */
    cels_register(TextInteraction);
    cels_session(World) {
        while (sdl3_should_run()) {
            float dt = sdl3_delta();
            cels_step(dt);
        }
    }
    printf("Text demo complete -- clean exit\n");
}
```
