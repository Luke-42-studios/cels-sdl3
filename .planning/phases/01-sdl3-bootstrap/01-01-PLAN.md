  <action>
Create four tightly-coupled source files following cels-ncurses patterns. Reference 01-RESEARCH.md Examples 3 and 4 as blueprints.

**include/cels_sdl3.h** (public API header):
- Include guard `CELS_SDL3_H`
- `#include <cels/cels.h>` and `#include <stdbool.h>`
- `CEL_Module(SDL3_Engine);` -- forward-declares the module (1-arity form)
- `CEL_Component(SDL3_ContextConfig)` with fields: `bool video;` -- developer configures what to init
- `CEL_Define_State(SDL3_ContextState)` with fields: `bool initialized; bool ttf_ready;` -- readable via `cel_read(SDL3_ContextState)`
- `CEL_Define_Composition(SDL3Context, bool video;);` -- composition parameter struct
- `#define SDL3Context(...) cel_init(SDL3Context, __VA_ARGS__)` -- call macro for natural syntax
- Comment block explaining usage: `#include <cels/cels.h>` then `#include <cels_sdl3.h>`
- Do NOT re-export `<cels/cels.h>` (it's already included, but document this mirrors cels-ncurses pattern)

**src/sdl3_internal.h** (internal declarations, NOT for consumers):
- Include guard `CELS_SDL3_INTERNAL_H`
- `#include <cels_sdl3.h>`
- Forward-declare init/shutdown functions:
  - `extern void sdl3_init(const SDL3_ContextConfig* config);`
  - `extern void sdl3_shutdown(void);`

**src/sdl3_module.c** (module definition -- ALL CELS declarations here per Pitfall 5):
- `#include <cels_sdl3.h>` and `#include "sdl3_internal.h"`
- `CEL_State(SDL3_ContextState);` -- registers the state in this TU
- `CEL_Lifecycle(SDL3_ContextLC);` -- defines the lifecycle
- `CEL_Observe(SDL3_ContextLC, on_create)`:
  - `const SDL3_ContextConfig* config = cel_watch(entity, SDL3_ContextConfig);`
  - If config is NULL, return early
  - Call `sdl3_init(config);`
- `CEL_Observe(SDL3_ContextLC, on_destroy)`:
  - `(void)entity;`
  - Call `sdl3_shutdown();`
- `CEL_Module(SDL3_Engine, init)`:
  - `cels_register(SDL3_ContextState, SDL3_ContextLC, SDL3_ContextConfig);`
- `CEL_Composition(SDL3Context)`:
  - `cel_has(SDL3_ContextConfig, .video = cel.video);`
  - `cels_lifecycle_bind_entity(SDL3_ContextLC_id, cels_get_current_entity());`

**src/sdl3_init.c** (init/shutdown implementation -- owns state data):
- `#include <cels_sdl3.h>` and `#include "sdl3_internal.h"`
- `#include <SDL3/SDL.h>` and `#include <SDL3_ttf/SDL_ttf.h>`
- Static state: `static struct SDL3_ContextState SDL3_ContextState = { .initialized = false };`
- `sdl3_init(const SDL3_ContextConfig* config)`:
  - If `SDL3_ContextState.initialized`, return early (prevent double-init)
  - Call `SDL3_ContextState_register(); cels_state_bind(SDL3_ContextState);` to register state
  - If `config->video`: call `SDL_Init(SDL_INIT_VIDEO)` -- returns `bool`, check with `if (!SDL_Init(...))`. On failure: `SDL_Log("SDL_Init failed: %s", SDL_GetError()); return;`
  - Call `TTF_Init()` -- returns `bool`. On failure: `SDL_Log("TTF_Init failed: %s", SDL_GetError()); SDL_Quit(); return;`
  - Set `SDL3_ContextState.initialized = true; SDL3_ContextState.ttf_ready = true;`
  - Do NOT call IMG_Init() -- SDL3_image has removed it (auto-initializes)
- `sdl3_shutdown()`:
  - If `!SDL3_ContextState.initialized`, return early
  - Call `TTF_Quit();` FIRST (reverse order)
  - Do NOT call IMG_Quit() -- SDL3_image has removed it
  - Call `SDL_Quit();` LAST
  - Set `SDL3_ContextState.initialized = false; SDL3_ContextState.ttf_ready = false;`

CRITICAL ANTI-PATTERNS (from research):
- Do NOT call `IMG_Init()` or `IMG_Quit()` -- removed in SDL3_image 3.x, will cause linker errors
- Do NOT check `SDL_Init()` return as int -- it returns `bool` in SDL3 (use `if (!SDL_Init(...))`)
- Do NOT call `SDL_Quit()` before `TTF_Quit()` -- wrong order causes use-after-free
- All CEL_Observe, CEL_Lifecycle, CEL_Module code MUST be in sdl3_module.c (Pitfall 5: per-TU static IDs)
  </action>
