  <action>
Create the minimal example app following the consumer usage pattern from 01-RESEARCH.md Example 4.

Create `examples/minimal/main.c`:

```c
#include <cels/cels.h>
#include <cels_sdl3.h>

CEL_Compose(World) {
    SDL3Context(.video = true) {}
}

cels_main() {
    cels_register(SDL3_Engine);
    cels_session(World) {
        // SDL3 is now initialized via lifecycle observer
        // Run a few frames to prove the loop works, then exit
        int frames = 0;
        while (cels_running() && frames < 5) {
            cels_step(0.016f);
            frames++;
        }
        // SDL3 shuts down automatically when World entity is destroyed
    }
}
```

This app:
1. Includes cels and cels_sdl3 headers
2. Defines a World composition with an SDL3Context entity (video=true)
3. Registers the SDL3_Engine module (triggers CEL_Module(SDL3_Engine, init))
4. Opens a cels_session which creates the World entity (triggers on_create observer -> sdl3_init)
5. Runs 5 ECS steps at 60fps delta time
6. Exits the session (triggers on_destroy observer -> sdl3_shutdown)

The example directory should already exist if CMakeLists.txt references it. Create `examples/minimal/` directory if needed.

Note: The example CMakeLists.txt for the minimal target is already in the main CMakeLists.txt (conditional on top-level build), matching the cels-ncurses pattern. No separate examples/minimal/CMakeLists.txt is needed.
