<task type="auto">
  <name>Task 1: Input example app with keyboard and mouse event reading</name>
  <files>
    examples/input/main.c
  </files>
  <action>
  Create `examples/input/main.c` following the same structure as `examples/frame-loop/main.c`.

  **World composition:**
  - Single window with `.context = true`, `.target_fps = 60` (lower FPS to keep console output readable), title "Input Demo", 800x600.

  **InputLogger system (OnUpdate phase):**
  - Queries `SDL3_EventQueue` via `cel_query(SDL3_EventQueue); cel_each(SDL3_EventQueue) { ... }`
  - Iterates `SDL3_EventQueue->events[0..count-1]` with a plain for-loop
  - Switches on `event.type`:
    - `SDL_EVENT_KEY_DOWN`:
      - If `event.key.key == SDLK_ESCAPE`: print "Escape pressed -- closing" and call `cel_quit()`
      - Else: print the key name using `SDL_GetKeyName(event.key.key)`. Only log non-repeat presses (`!event.key.repeat`) to avoid flooding console.
    - `SDL_EVENT_KEY_UP`:
      - Print "Key released: <name>" (non-repeat only, same SDL_GetKeyName pattern)
    - `SDL_EVENT_MOUSE_BUTTON_DOWN`:
      - Print "Mouse button %d pressed at (%.0f, %.0f)" using `event.button.button`, `event.button.x`, `event.button.y`
    - `SDL_EVENT_MOUSE_MOTION`:
      - Use a static frame counter or accumulator to log mouse position periodically (e.g., every 30th motion event or once per second), NOT every motion event. Print "Mouse position: (%.0f, %.0f)" using `event.motion.x`, `event.motion.y`.
    - Default: ignore (no catch-all logging)

  **No convenience macros** -- the for-loop + switch is the intended consumer pattern per CONTEXT.md.

  **Main function (cels_main):**
  - Same pattern as frame-loop example:
    ```c
    cels_main() {
        cels_register(SDL3_Engine);
        cels_register(InputLogger);
        cels_session(World) {
            while (sdl3_should_run()) {
                float dt = sdl3_delta();
                cels_step(dt);
            }
        }
        printf("Input demo complete -- clean exit\n");
    }
    ```

  **Console output behavior (from CONTEXT.md):**
  - Key presses: logged individually (each press = one line)
  - Mouse position: logged on click or periodically (NOT every frame)
  - No renderer needed -- console output only
  - Clean exit message on shutdown

  **Include headers:** `<cels/cels.h>`, `<cels_sdl3.h>`, `<stdio.h>`

  - Follows same code structure as frame-loop example (CEL_Compose World, CEL_System, cels_main with consumer loop)
