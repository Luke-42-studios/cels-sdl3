  **1. Add SDL3_EventQueue component to cels_sdl3.h:**

  After the Frame Loop Types section (before `#endif`), add an Input System section:

  ```c
  /* ============================================================================
   * Input System Types
   * ============================================================================ */

  #define SDL3_EVENT_QUEUE_CAPACITY 64

  CEL_Component(SDL3_EventQueue) {
      SDL_Event events[SDL3_EVENT_QUEUE_CAPACITY];
      int       count;
  };
  ```

  This is a fixed-size array of raw SDL_Event structs (128 bytes each = 8 KiB per component). No wrapper types, no abstraction -- per CONTEXT.md decision. Queue is cleared every frame.

  **2. Add input function declarations to sdl3_internal.h:**

  After the loop lifecycle declarations, add:

  ```c
  /* Input system -- called from sdl3_module.c systems */
  extern void sdl3_input_drain_events(cels_entity_t wc_id, cels_entity_t eq_id);
  ```

  Single function that handles everything: clear queues, check minimized-pause, poll events, route window events, buffer input events. The component IDs are passed as parameters because sdl3_input.c cannot use CELS macros (per-TU static ID constraint -- same pattern as sdl3_window.c and sdl3_loop.c).

  **3. Create src/input/sdl3_input.c:**

  Remove the existing `.gitkeep` and create the implementation file. Follow the existing file patterns (see sdl3_loop.c, sdl3_window.c).

  The file implements one public function: `sdl3_input_drain_events(wc_id, eq_id)`.

  **Internal structure of the function (single-pass drain):**

  Phase A -- Clear all queues:
  - Iterate all entities with SDL3_EventQueue, set `count = 0`.
  - Use `cels_query_init`/`cels_query_next` (or the equivalent low-level API that works outside the macro TU -- check how sdl3_window.c accesses components via `cels_entity_set_component` and `cels_entity_get_component`).
  - Important: Since this file cannot use `cel_query`/`cel_each` macros (per-TU constraint), use the raw CELS entity API. The pattern from sdl3_window.c is `cels_entity_set_component(entity, component_id, &data, sizeof(data))`. For iteration, you need to query entities that have both SDL3_WindowComponent and SDL3_EventQueue. Use `cels_query_create` with both component IDs, then iterate with `cels_query_next`.
  - IMPORTANT: Look at how the existing EventPumpSystem in sdl3_module.c iterates windows (`cel_query(SDL3_WindowComponent); cel_each(SDL3_WindowComponent) { ... }`). Since we cannot use those macros in sdl3_input.c, the drain function will be called FROM the system in sdl3_module.c. The system body itself (in sdl3_module.c) will use `cel_query`/`cel_each` for the clear phase, OR the drain function can use the low-level API. Choose whichever approach is cleaner -- the RESEARCH.md suggests the drain function receives component IDs and uses the raw API internally.
  - The simplest approach: Have the SDL3_InputSystem in sdl3_module.c call `sdl3_input_drain_events(SDL3_WindowComponent_id, SDL3_EventQueue_id)`, and inside sdl3_input.c, use `cels_query_create`/`cels_query_next` to iterate entities. Check the CELS framework headers (`/home/cachy/workspaces/libs/cels/include/cels/cels.h`) for the available low-level query API.

  Phase B -- Check minimized pause:
  - Same logic as current EventPumpSystem lines 73-117 (count total windows, count minimized).
  - If all windows minimized: call `SDL_WaitEvent(&event)`, handle the waking event (quit -> `cel_quit()`, window events -> route to `sdl3_window_handle_event`, others -> push to matching queue), then return.

  Phase C -- Normal poll loop:
  - `while (SDL_PollEvent(&event))`:
    - `SDL_EVENT_QUIT` -> `cel_quit(); return;`
    - Window lifecycle events (`SDL_EVENT_WINDOW_CLOSE_REQUESTED`, `SDL_EVENT_WINDOW_MINIMIZED`, `SDL_EVENT_WINDOW_RESTORED`, `SDL_EVENT_WINDOW_RESIZED`, `SDL_EVENT_WINDOW_FOCUS_GAINED`, `SDL_EVENT_WINDOW_FOCUS_LOST`) -> find matching window entity by `event.window.windowID`, call `sdl3_window_handle_event`. These NEVER enter the raw queue.
    - All other events -> find matching window entity by extracting windowID from the event (most SDL3 input events have a `windowID` field), push into that entity's SDL3_EventQueue. If no matching window found (windowID == 0 or stale), drop silently.

  **Static helper function:**
  ```c
  static void push_event(SDL3_EventQueue* queue, const SDL_Event* event) {
      if (queue->count < SDL3_EVENT_QUEUE_CAPACITY) {
          queue->events[queue->count++] = *event;
      }
      // else: overflow -- silently drop
  }
  ```

  **windowID extraction helper:**
  SDL3 events carry windowID in different union members depending on type. For keyboard events: `event.key.windowID`. For mouse motion: `event.motion.windowID`. For mouse button: `event.button.windowID`. For mouse wheel: `event.wheel.windowID`. For text input: `event.text.windowID`. The simplest robust approach: use `event.window.windowID` only for window events. For all other events, extract windowID based on event type category. Alternatively, since SDL3 consistently places windowID at the same offset in most event structs that have one, you can use a helper that switches on event type range. Keep it simple -- a switch or if-else that covers the main categories (keyboard, mouse motion, mouse button, mouse wheel, text input).

  **Important notes:**
  - Include `<cels_sdl3.h>` and `"../sdl3_internal.h"` (same include pattern as other src files).
  - The file CANNOT use `CEL_System`, `CEL_Component`, `cel_query`, `cel_each`, `cel_update`, `cel_quit` macros directly. It must use the raw CELS C API.
  - For `cel_quit()`: check if there's a raw function like `cels_quit()` or `cels_set_running(false)`. If not, the quit handling can stay in the sdl3_module.c system wrapper, and the drain function can return a status code indicating quit was requested.
  - Actually, re-examining the architecture: `cel_quit()` is likely a macro that expands to something callable from any TU. Check the CELS headers. If it works from sdl3_input.c, use it directly. If not, have the drain function return a bool and let the system in sdl3_module.c call `cel_quit()`.
