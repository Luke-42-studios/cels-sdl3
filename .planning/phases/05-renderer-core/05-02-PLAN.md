  <action>
    **1. Create examples/renderer/main.c**

    Create the renderer directory and main.c following the established example pattern from examples/input/main.c:

    - File header comment explaining what the example demonstrates
    - Standard includes: `cels/cels.h`, `cels_sdl3.h`, `stdio.h`
    - CEL_Compose(World) creating a single window: `SDL3Window(.title = "Renderer Demo", .width = 800, .height = 600, .context = true, .target_fps = 60) {}`
    - A `ColorChanger` system at `OnUpdate` phase that reads SDL3_EventQueue and SDL3_Renderer, using the event consumer pattern (raw for-loop + switch on events[0..count-1]):
      - R key: set clear_color to red `(SDL_Color){255, 0, 0, 255}`
      - G key: set clear_color to green `(SDL_Color){0, 255, 0, 255}`
      - B key: set clear_color to blue `(SDL_Color){0, 0, 255, 255}`
      - C key: set clear_color to cornflower blue `(SDL_Color){100, 149, 237, 255}` (reset)
      - Escape key: `cel_quit()` to close
      - Use `cel_update(SDL3_Renderer)` when modifying clear_color
      - Print a message on each color change: `printf("Color: red\n")` etc.
      - Only respond to SDL_EVENT_KEY_DOWN (not repeats: check `!ev->key.repeat`)
    - Standard cels_main() with `cels_register(SDL3_Engine)`, `cels_register(ColorChanger)`, session loop, and exit message
    - The query in ColorChanger needs BOTH SDL3_EventQueue and SDL3_Renderer:
      ```c
      cel_query(SDL3_EventQueue, SDL3_Renderer);
      cel_each(SDL3_EventQueue, SDL3_Renderer) { ... }
      ```

    **2. Update CMakeLists.txt**

    Add the renderer example target in the examples section, following the exact pattern of the existing input example:

    ```cmake
    add_executable(renderer examples/renderer/main.c)
    target_link_libraries(renderer PRIVATE cels-sdl3)
    set_target_properties(renderer PROPERTIES C_STANDARD 99 C_STANDARD_REQUIRED ON)
    ```

    **3. Build and verify**

    Build all targets. Run the renderer example under SDL_VIDEODRIVER=dummy to verify it starts, runs a few frames, and exits cleanly without crashes. Also verify all other existing examples still build.
