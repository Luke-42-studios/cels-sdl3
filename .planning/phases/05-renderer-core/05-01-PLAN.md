Implement SDL3_Renderer as a paired ECS component on each window entity, with automatic lifecycle management and a clear/present render cycle using CELS pipeline phases.

Purpose: This is the rendering foundation -- every subsequent phase (draw primitives, textures, text) depends on having a working renderer per window with a clear/present cycle that developer draw systems slot into.

Output: SDL3_Renderer component type, renderer create/destroy functions, RenderClear (PreRender) and RenderPresent (PostRender) systems, module wiring with correct registration and lifecycle ordering.
</objective>

    - `sdl3_renderer_create(entity, window, component_id)`:
      - Call `SDL_DestroyWindowSurface(window)` first to release the Wayland surface hack from sdl3_window_create. This is REQUIRED because SDL_GetWindowSurface and SDL_CreateRenderer are mutually exclusive on the same window.
      - Call `SDL_CreateRenderer(window, NULL)` -- NULL lets SDL pick optimal driver
      - If renderer is NULL, log error with SDL_GetError() and return (no crash)

      - Call `cels_entity_set_component(entity, component_id, &comp, sizeof(comp))` to attach to entity
    - `sdl3_renderer_destroy(renderer)`:
      - Guard with `if (!renderer) return;`
      - Call `SDL_DestroyRenderer(renderer)` -- this also frees all associated textures

    Follow the exact same file structure and style as sdl3_window.c (same header comment pattern, same include style).

    **1. Add renderer creation to SDL3_WindowLC on_create observer**

    In the `CEL_Observe(SDL3_WindowLC, on_create)` function, AFTER the existing `sdl3_window_create(entity, config, SDL3_WindowComponent_id)` call and AFTER the SDL3_EventQueue attachment block, add:

    ```c
    /* Create renderer for this window -- must happen after window creation
     * since sdl3_renderer_create needs the SDL_Window* from the component.
     * Re-read the window component to get the created window pointer. */
    const SDL3_WindowComponent* win_comp =
        (const SDL3_WindowComponent*)cels_entity_get_component(
            entity, SDL3_WindowComponent_id);
    if (win_comp && win_comp->window) {
        sdl3_renderer_create(entity, win_comp->window, SDL3_Renderer_id);
    }
    ```

    Note: We need to read back the window component because sdl3_window_create sets it via cels_entity_set_component (we don't have a local pointer to the stored component). Use cels_entity_get_component to retrieve the stored component and get the SDL_Window* pointer.

    IMPORTANT: If cels_entity_get_component is not available in the CELS API, an alternative approach is to have sdl3_window_create return the SDL_Window* pointer, or store it in a local variable. Check the CELS headers for the available API. The window pointer is set inside sdl3_window_create via SDL_CreateWindow -- the simplest approach may be to modify sdl3_window_create to return the SDL_Window* pointer (changing void return to SDL_Window* return) and use that directly:

    ```c
    SDL_Window* window = sdl3_window_create(entity, config, SDL3_WindowComponent_id);
    if (window) {
        sdl3_renderer_create(entity, window, SDL3_Renderer_id);
    }
    ```

    If taking this approach, update the declaration in sdl3_internal.h to return SDL_Window* and modify sdl3_window.c to `return window;` (and `return NULL;` on error). This is the cleaner solution. Choose whichever approach works with the available CELS API.

    **2. Add renderer destruction to SDL3_WindowStateSystem**

    In the `CEL_System(SDL3_WindowStateSystem)` body, inside the `if (SDL3_WindowComponent->state == SDL3_WINDOW_CLOSING)` block, BEFORE the existing `sdl3_window_destroy(SDL3_WindowComponent->window)` call:

    - Query the SDL3_Renderer component for this entity to get the renderer pointer
    - Call `sdl3_renderer_destroy(renderer_pointer)` BEFORE `sdl3_window_destroy`
    - SDL_DestroyRenderer MUST happen before SDL_DestroyWindow (SDL docs requirement)

    The tricky part: WindowStateSystem currently queries only SDL3_WindowComponent. To access the SDL3_Renderer component, the system query must include SDL3_Renderer. Change the system to query both:

    ```c
    CEL_System(SDL3_WindowStateSystem, .phase = OnLoad) {
        cel_query(SDL3_WindowComponent, SDL3_Renderer);
        cel_each(SDL3_WindowComponent, SDL3_Renderer) {
            if (SDL3_WindowComponent->state == SDL3_WINDOW_CLOSING) {
                bool owns_context = SDL3_WindowComponent->context_bound;
                /* Destroy renderer BEFORE window (SDL requirement) */
                if (SDL3_Renderer->renderer) {
                    sdl3_renderer_destroy(SDL3_Renderer->renderer);
                    cel_update(SDL3_Renderer) {
                        SDL3_Renderer->renderer = NULL;
                    }
                }
                if (SDL3_WindowComponent->window) {
                    sdl3_window_destroy(SDL3_WindowComponent->window);
                }
                cel_update(SDL3_WindowComponent) {
                    SDL3_WindowComponent->window = NULL;
                    SDL3_WindowComponent->state = SDL3_WINDOW_CLOSED;
                }
                cels_component_notify_change(SDL3_WindowComponent_id);
                if (owns_context) {
                    sdl3_shutdown();
                    sdl3_frame_set_running(false);
                }
            }
        }
    }
    ```

    **3. Add SDL3_RenderClearSystem (PreRender phase)**

    Add a new system AFTER the FrameStateSystem section. This system runs at the PreRender phase and clears each window's renderer to its clear color:

    ```c
    CEL_System(SDL3_RenderClearSystem, .phase = PreRender) {
        cel_query(SDL3_WindowComponent, SDL3_Renderer);
        cel_each(SDL3_WindowComponent, SDL3_Renderer) {
            /* Skip windows that should not render */
            if (SDL3_WindowComponent->state == SDL3_WINDOW_MINIMIZED ||
                SDL3_WindowComponent->state == SDL3_WINDOW_CLOSING ||
                SDL3_WindowComponent->state == SDL3_WINDOW_CLOSED) continue;

            SDL_SetRenderDrawColor(SDL3_Renderer->renderer,
                SDL3_Renderer->clear_color.r,
                SDL3_Renderer->clear_color.g,
                SDL3_Renderer->clear_color.b,
                SDL3_Renderer->clear_color.a);
            SDL_RenderClear(SDL3_Renderer->renderer);
        }
    }
    ```

    Do NOT wrap the SDL calls in cel_update -- the component struct fields are not being modified. The SDL-internal backbuffer mutation is outside ECS tracking. Using cel_update would trigger unnecessary change notifications.

    **4. Add SDL3_RenderPresentSystem (PostRender phase)**

    Add a system immediately after RenderClearSystem:

    ```c
    CEL_System(SDL3_RenderPresentSystem, .phase = PostRender) {
        cel_query(SDL3_WindowComponent, SDL3_Renderer);
        cel_each(SDL3_WindowComponent, SDL3_Renderer) {
            if (SDL3_WindowComponent->state == SDL3_WINDOW_MINIMIZED ||
                SDL3_WindowComponent->state == SDL3_WINDOW_CLOSING ||
                SDL3_WindowComponent->state == SDL3_WINDOW_CLOSED) continue;

            SDL_RenderPresent(SDL3_Renderer->renderer);
        }
    }
    ```

    Same pattern as clear system -- no cel_update, just read the renderer pointer and call SDL.

    **5. Update CEL_Module(SDL3_Engine, init) registration**

    Add SDL3_Renderer, SDL3_RenderClearSystem, and SDL3_RenderPresentSystem to the module registration. The render systems should be registered after the existing OnLoad-phase systems:

    ```c
    cels_register(SDL3_WindowConfig, SDL3_WindowComponent, SDL3_EventQueue,
                  SDL3_Renderer,
                  SDL3_WindowLC, SDL3_WindowStateSystem);
    cels_register(SDL3_FrameStateSystem);
    cels_register(SDL3_RenderClearSystem);
    cels_register(SDL3_RenderPresentSystem);
    ```

    Add SDL3_Renderer to the line that registers window-related components. Register the render systems on separate lines AFTER FrameStateSystem to establish ordering: OnLoad systems run first (input, window state, frame state), then PreRender (clear), then PostRender (present).

    Also add cels_ensure_component for SDL3_Renderer_id (same pattern as SDL3_EventQueue_id):

    ```c
    cels_ensure_component(&SDL3_Renderer_id, "SDL3_Renderer",
                          sizeof(SDL3_Renderer), CELS_ALIGNOF(SDL3_Renderer));
    ```

    This is needed because the on_create observer uses SDL3_Renderer_id before any system body runs (same issue as SDL3_EventQueue from Phase 4).
