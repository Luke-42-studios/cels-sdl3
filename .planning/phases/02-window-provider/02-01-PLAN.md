  ```c

   * SDL3 Window - Creation, Destruction, State Machine

  ```

  Implement `sdl3_window_create(entity, config, component_id)`:
  - Default title to "" if NULL or empty
  - Default width to 1280 if <= 0
  - Default height to 720 if <= 0
  - OR in SDL_WINDOW_RESIZABLE by default UNLESS SDL_WINDOW_BORDERLESS is set in flags (context decision: resizable by default)
  - Call `SDL_CreateWindow(title, w, h, flags)` -- the 4-parameter SDL3 signature (NOT the SDL2 6-parameter one)
  - If SDL_CreateWindow fails, log with `SDL_Log("SDL3: SDL_CreateWindow failed: %s", SDL_GetError())` and return
  - Build SDL3_WindowComponent with: .window = window, .window_id = SDL_GetWindowID(window), .state = SDL3_WINDOW_READY, .width = w, .height = h
  - The state advances synchronously: NONE -> CREATED -> SURFACE_READY -> READY all happen during creation. Set the final state directly to READY (SURFACE_READY is instant pass-through for SDL_Renderer path per RESEARCH.md Open Question 2)
  - Attach via `cels_entity_set_component(entity, component_id, &comp, sizeof(comp))`
  - Call `cels_component_notify_change(component_id)`

  Implement `sdl3_window_destroy(SDL_Window* window)`:
  - If window is NULL, return
  - Call `SDL_DestroyWindow(window)`

  Implement `sdl3_window_handle_event(SDL3_WindowComponent* comp, Uint32 event_type, int data1, int data2)`:
  - This function drives state transitions from SDL events. Phase 4 will call this when routing window events.
  - Switch on event_type:
    - `SDL_EVENT_WINDOW_CLOSE_REQUESTED`: If state != CLOSED, set state = SDL3_WINDOW_CLOSING
    - `SDL_EVENT_WINDOW_MINIMIZED`: If state == READY, set state = SDL3_WINDOW_MINIMIZED
    - `SDL_EVENT_WINDOW_RESTORED`: If state == MINIMIZED, set state = SDL3_WINDOW_SURFACE_READY, then immediately set state = SDL3_WINDOW_READY (synchronous restore chain per CONTEXT.md: MINIMIZED -> SURFACE_READY -> READY)
    - `SDL_EVENT_WINDOW_RESIZED`: If state == READY or state == SDL3_WINDOW_RESIZING, set state = SDL3_WINDOW_RESIZING, update comp->width = data1, comp->height = data2
    - Default: no-op (informational events like focus/expose are ignored)
  - Note: CLOSING -> CLOSED transition is NOT handled by this function. That transition happens in the state system (one frame delay per CONTEXT.md: "CLOSING gives one frame before CLOSED"). The state system in sdl3_module.c will handle that.

  **1. Extend `src/sdl3_module.c`** with window CELS declarations. Follow the existing pattern exactly (context lifecycle section is the model).

  Add `#include <SDL3/SDL.h>` if not already present.

  Add Window Lifecycle section (after the Context Lifecycle section):
  ```c
  /* ============================================================================
   * Window Lifecycle
   * ============================================================================ */

  CEL_Lifecycle(SDL3_WindowLC);

  CEL_Observe(SDL3_WindowLC, on_create) {
      const SDL3_WindowConfig* config = cel_watch(entity, SDL3_WindowConfig);
      if (!config) return;
      sdl3_window_create(entity, config, SDL3_WindowComponent_id);
  }

  CEL_Observe(SDL3_WindowLC, on_destroy) {
      const SDL3_WindowComponent* comp = cel_watch(entity, SDL3_WindowComponent);
      if (comp && comp->window) {
          sdl3_window_destroy(comp->window);
      }
  }
  ```

  Note: `sdl3_window_create` receives `SDL3_WindowComponent_id` explicitly -- this is how the per-TU static ID reaches sdl3_window.c.

  Add Window State System section (after Window Lifecycle). This system runs each frame and handles the CLOSING -> CLOSED transition (one frame delay per CONTEXT.md):
  ```c
  /* ============================================================================
   * Window State System -- per-frame state machine driver
   * ============================================================================ */

  CEL_System(SDL3_WindowStateSystem, .phase = OnLoad) {
      cel_query(SDL3_WindowComponent);
      cel_each(SDL3_WindowComponent) {
          if (SDL3_WindowComponent->state == SDL3_WINDOW_CLOSING) {
              /* CLOSING -> CLOSED: one frame has elapsed since close request.
               * Destroy the SDL_Window and mark terminal state. */
              if (SDL3_WindowComponent->window) {
                  sdl3_window_destroy(SDL3_WindowComponent->window);
              }
              cel_update(SDL3_WindowComponent) {
                  SDL3_WindowComponent->window = NULL;
                  SDL3_WindowComponent->state = SDL3_WINDOW_CLOSED;
              }
          }
      }
  }
  ```

  Update the `CEL_Module(SDL3_Engine, init)` block to register window types:
  ```c
  CEL_Module(SDL3_Engine, init) {
      cels_register(SDL3_ContextState, SDL3_ContextLC,
                    SDL3_ContextConfig);
      cels_register(SDL3_WindowConfig, SDL3_WindowComponent,
                    SDL3_WindowLC, SDL3_WindowStateSystem);
  }
  ```

  Add SDL3Window Composition section (after the existing SDL3Context composition):
  ```c
  CEL_Composition(SDL3Window) {
      cel_has(SDL3_WindowConfig,
          .title  = cel.title,
          .width  = cel.width  ? cel.width  : 1280,
          .height = cel.height ? cel.height : 720,
          .flags  = cel.flags | SDL_WINDOW_RESIZABLE
      );
      cels_lifecycle_bind_entity(SDL3_WindowLC_id, cels_get_current_entity());
  }
  ```

  Note: The composition always ORs in SDL_WINDOW_RESIZABLE. If the developer wants to disable resizing, they must explicitly use `SDL_WINDOW_BORDERLESS` in their flags (borderless windows aren't resizable by drag handles anyway). The sdl3_window_create function also handles the borderless-skips-resizable check as a safety net.
